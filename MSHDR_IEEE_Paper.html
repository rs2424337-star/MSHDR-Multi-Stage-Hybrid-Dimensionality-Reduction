Multi-Stage Hybrid Dimensionality Reduction for
SOC Network Intrusion Detection
Riya
April 2026
Abstract
Security Operations Centres (SOCs) process high-velocity network log data where the curse of dimensionality remains a bottleneck for efficient threat detection. This paper presents a Multi-Stage Hybrid Dimensionality Reduction (MSHDR) framework that compresses high-dimensional SOC features into a compact, class-discriminative latent space. We introduce the Supervised Contrastive Manifold-Aware Autoencoder (SCMAA), which combines adaptive ensemble feature selection, Fisher-weighted manifold fusion, and a Supervised Contrastive Variational Autoencoder (SCVAE) with β-annealing curriculum learning. On a dataset of 46,662 labelled network connection records, the SCMAA pipeline compresses 14 input features to 4 latent dimensions while achieving 99.76% classification accuracy and 99.99% AUC-ROC. These results effectively match the performance of uncompressed features (100%) and linear baselines such as PCA (99.82%). Our findings confirm that incorporating supervised label information into the generative compression process preserves class separability under extreme dimensionality reduction.
Keywords — Dimensionality reduction, SOC intrusion detection, manifold fusion, supervised contrastive learning, variational autoencoder, SCMAA.

I. Introduction

Security Operations Centres (SOCs) routinely ingest millions of network connection records per day. The sheer volume of features attached to each record slows down downstream classifiers and inflates storage costs. Wright et al. [1] report that over 99% of raw security data is noise, which makes intelligent pre-processing essential before any classification pipeline can operate at scale.

Dimensionality reduction—the mapping of a high-dimensional feature space to a lower-dimensional representation that retains discriminative information—has become a standard preprocessing step in network intrusion detection. However, most existing approaches either rely on unsupervised compression (which ignores label structure) or treat feature selection and manifold learning as isolated stages rather than components of a single coordinated pipeline.

This paper presents and evaluates the Multi-Stage Hybrid Dimensionality Reduction (MSHDR) framework, a Python-based research pipeline applied to SOC network intrusion detection. The pipeline is benchmarked against five classical baselines on a cleaned dataset of 46,662 samples with 14 features, labelled as normal or attack traffic.

The central research question is: Can a hybrid multi-stage strategy—combining feature selection, manifold fusion, and deep generative compression—produce a compact latent representation that matches the classification accuracy of the unreduced feature space?

We describe two iterations of the pipeline. MSHDR v1 uses a reconstruction-only autoencoder and suffers from a failure mode where class structure is destroyed during compression. MSHDR v2 addresses this with the Supervised Contrastive Manifold-Aware Autoencoder (SCMAA), which incorporates label supervision at every stage and achieves 99.76% accuracy in just 4 latent dimensions.

The paper is organised as follows. Section II reviews related work. Section III identifies gaps in the existing literature. Section IV describes the methodology. Section V presents experimental results. Section VI provides a code-level technical analysis. Section VII concludes with lessons learned.

II. Related Work

A. Autoencoders for Dimensionality Reduction

An autoencoder is an unsupervised neural network that learns to compress input data into a lower-dimensional latent representation and reconstruct the original from that compressed form [2]. The architecture has three components: an encoder mapping input $x \in \mathbb{R}^d$ to a bottleneck $z \in \mathbb{R}^k$ where $k \ll d$; the bottleneck layer itself; and a decoder that reconstructs $\hat{x}$ from $z$. Training minimises reconstruction error, typically mean squared error:

$$\mathcal{L}_{recon} = \| x - \hat{x} \|^2 \qquad (1)$$

Because information must pass through a narrow bottleneck, the network is forced to retain only the most salient structure of the input distribution [3]. Unlike PCA, which captures variance along linear subspaces, autoencoders can model nonlinear transformations, which makes them better suited to heterogeneous security data with complex inter-feature relationships [1].

Several autoencoder variants have extended the basic architecture. Denoising autoencoders train on corrupted inputs to improve robustness [4]. Sparse autoencoders enforce activation sparsity so that only a small subset of hidden units fire, which emphasises discriminative features [5], [6]. Variational autoencoders (VAEs) encode to a probability distribution $q(z|x) = \mathcal{N}(\mu, \sigma^2)$ rather than a deterministic point, with a KL divergence term regularising the latent space:

$$\mathcal{L}_{VAE} = \mathcal{L}_{recon} + \beta \cdot D_{KL}(q(z|x) \| p(z)) \qquad (2)$$

VAEs tend to generalise better and resist overfitting compared to deterministic autoencoders [7]. The $\beta$-VAE variant (with $\beta > 1$) encourages a more disentangled latent space.

The most advanced variant considered here is the Supervised Contrastive VAE (SCVAE), which extends the VAE with a supervised contrastive loss [8] and a classification head. The resulting multi-task loss is:

$$\mathcal{L} = \alpha \cdot \mathcal{L}_{recon} + \beta(t) \cdot D_{KL} + \gamma \cdot \mathcal{L}_{SupCon} + \delta \cdot \mathcal{L}_{CE} \quad (3)$$

This formulation—implemented in the MSHDR v2 pipeline—produces a latent space that is simultaneously compact (reconstruction), well-regularised (KL), class-discriminative (supervised contrastive), and optimised for the downstream classification task (cross-entropy). The MSHDR project implements both a reconstruction-only autoencoder (v1, TensorFlow/Keras) and the full SCVAE (v2, PyTorch), enabling a direct empirical comparison of these two paradigms.

B. The Curse of Dimensionality in SOC Data

The curse of dimensionality [9] describes the exponential growth in data sparsity as the feature count $d$ increases. In high-dimensional spaces, pairwise distances converge and distance-based learning algorithms degrade [10]. In cybersecurity contexts specifically, high-dimensional features inflate computational overhead in SIEM pipelines, redundant features introduce spurious correlations, and storage costs scale with dimensionality. Wright et al. [1] compressed SOC log storage from 142,509 KB to 11,685 KB—an 8× reduction—while maintaining classifier accuracy above 99%.

PCA addresses dimensionality by identifying directions of maximum variance through eigenvalue decomposition of the covariance matrix. On the 46,662-sample dataset used here, PCA retains 95% of variance in 4 principal components and achieves 99.82% classification accuracy, which suggests the dataset has very low intrinsic dimensionality and that linear projections already capture most of the discriminative structure.

Linear Discriminant Analysis (LDA) takes a supervised approach, projecting data onto directions that maximise inter-class separability relative to intra-class scatter via the Fisher criterion:

$$J = \frac{\text{tr}(S_B)}{\text{tr}(S_W)} \qquad (4)$$

For binary classification, LDA reduces to a single dimension. On this dataset it achieves 97.89% accuracy—a notable compression from 14 dimensions to 1. The MSHDR v2 pipeline uses a generalised multiclass Fisher criterion $J = \text{tr}(S_W^{-1} S_B)$ to score and weight each manifold embedding method in its fusion stage.

C. Baseline Dimensionality Reduction Methods

The evaluation benchmarks five methods representing the major paradigms.

1) PCA:

An unsupervised linear method that identifies orthogonal directions of maximum variance [11]. A 95% variance threshold selects 4 components on this dataset. PCA is computationally efficient ($O(d^2 n)$) and fully invertible but cannot capture nonlinear manifold structure. It achieved 99.82% accuracy and 99.95% AUC-ROC.

2) LDA:

A supervised linear method that maximises the Fisher criterion. With $c = 2$ classes, LDA yields a single output dimension yet achieves 97.89% accuracy and 99.49% AUC-ROC, confirming strong linear separability.

3) t-SNE:

A nonlinear technique designed for 2D visualisation [12]. It minimises the KL divergence between pairwise similarity distributions in high- and low-dimensional space. Because t-SNE is non-parametric—it cannot transform unseen test points—its use in predictive settings is limited. Subsampled to 5,000 points (due to $O(n^2)$ complexity), it achieved 85.64% accuracy on this dataset.

4) UMAP:

A graph-based manifold method grounded in Riemannian geometry [13]. UMAP supports transform() on new data, scales as $O(n \log n)$, and preserves both local and global structure. With 2 components it achieved 94.34% accuracy.

5) Original features (no reduction):

A Random Forest classifier on all 14 features provides the oracle upper bound. It achieved 100% on all metrics, confirming the dataset is highly structured and separable.

D. Autoencoders in Network Security

The application of autoencoders to intrusion detection is well established. Lightweight systems such as Kitsune [14] use reconstruction error as an anomaly score: a model trained on normal traffic exhibits high reconstruction error on attack traffic, enabling zero-shot anomaly detection.

Wright et al. [1] present the most directly relevant prior work: autoencoder-based reduction of Zeek connection logs from a 303-feature space using five autoencoder models (MLP, 1D CNN, reconstruction-error, and stacked aggregation variants), producing 6 latent features. Downstream classifiers (logistic regression, MLP, SVM, and random forest) maintained above 99% accuracy under compression, and random forest actually improved with compressed features.

The MSHDR project operates in a different feature regime (14 features rather than 303) and employs a more sophisticated compression chain that incorporates supervised manifold fusion before the autoencoder stage. The principal novelty in MSHDR v2—supervised contrastive learning within the VAE training objective—addresses a limitation exposed by the MSHDR v1 failure: unsupervised reconstruction loss alone does not guarantee a class-discriminative latent space.

III. Identified Gaps in the Literature

Five gaps in the existing autoencoder-based dimensionality reduction literature motivate this work:

Gap 1: Unsupervised compression ignores class structure. The dominant paradigm trains autoencoders with reconstruction loss only, which optimises for variance reconstruction rather than class separability. The MSHDR v1 failure demonstrates this empirically: a bottleneck optimised for reconstruction can produce a latent space where class boundaries are entirely absent. Wright et al. [1] treat reconstruction error as an input feature but do not incorporate label supervision into the latent training objective itself.

Gap 2: Equal-weight manifold aggregation is suboptimal. Multi-stage pipelines that fuse multiple embeddings typically concatenate them with uniform or heuristic weights. This ignores each embedding's actual discriminative quality. LDA, as a supervised method, consistently produces more discriminative embeddings than PCA or Isomap for labelled data, but equal-weight concatenation dilutes its contribution.

Gap 3: Fixed ensemble weights do not adapt. Voting classifiers with predetermined weights assume static relative performance between base learners. In practice, the relative quality of Random Forest versus XGBoost varies with the feature distribution at each compression stage. A meta-learner trained on out-of-fold predictions adapts to actual empirical performance.

Gap 4: No curriculum learning in autoencoder training. Standard VAE training applies a constant KL weight $\beta$, which can cause posterior collapse—the model collapses the latent distribution to the prior before reconstruction quality is established. $\beta$-annealing [15] has been proposed as a remedy but is rarely applied in cybersecurity dimensionality reduction.

Gap 5: Limited evaluation of extreme compression. Wright et al. [1] evaluate reduction from 303 to 6 features (20× compression). The MSHDR project evaluates 14→4 compression, testing whether the discriminative structure of a moderately-sized feature set survives extreme compression through a supervised deep generative model.

IV. Methodology

A. Dataset

The dataset contains 46,662 samples with 14 numerical features and a binary label (0 = normal, 1 = attack). The class distribution is imbalanced: 63.23% attack (29,506 samples) and 36.77% normal (17,156 samples). No missing values are present. A stratified 80/20 train-test split yields 37,329 training and 9,333 test samples.

B. Evaluation Protocol

All methods are evaluated on accuracy, precision, recall, F1-score, and AUC-ROC. Baseline methods share a common Random Forest classifier (n_estimators=100, random_state=42) for fair comparison. MSHDR methods use their respective ensemble classifiers as integral pipeline components.

C. MSHDR v1 Pipeline

The v1 pipeline has four stages:

Stage 1 (Feature Selection): Mutual information scoring selects the top 8 features from the original 14.

Stage 2 (Manifold Fusion): PCA (3D), LDA (1D), and Isomap (2D) embeddings are concatenated into a 6D fused representation. Isomap is fitted on a 1,999-point subsample to manage its $O(n^2)$ complexity.

Stage 3 (Autoencoder Compression): A TensorFlow/Keras autoencoder trained exclusively on reconstruction loss compresses the 6D fused representation to 3D.

Stage 4 (Ensemble Classifier): A VotingClassifier with Random Forest and XGBoost at fixed weights [0.4, 0.6] classifies the compressed features.

D. MSHDR v2 Pipeline (SCMAA)

The v2 pipeline redesigns each stage to address the failures identified in v1:

Stage 1 (Adaptive Ensemble Feature Selection): Three scoring criteria are combined: mutual information (weight 0.4), ANOVA F-statistic (weight 0.3), and Random Forest importance (weight 0.3). The feature count cutoff is determined by elbow detection on the sorted ensemble scores, constrained to [5, 12] features. On this dataset, 5 features were selected: proto, conn_state, id.resp_p, id.orig_p, and orig_ip_bytes.

Fig. 1. Mutual information scores for all 14 features. The top features (id.resp_p, orig_ip_bytes, proto) carry the strongest class-discriminative signal. The elbow detection in MSHDR v2 selected the top 5 features.

Stage 2 (Fisher-Weighted Manifold Fusion): Four embedding methods (PCA, LDA, Isomap, UMAP) are each scored by the multiclass Fisher criterion $J = \text{tr}(S_W^{-1} S_B)$ on training data. Softmax attention weights are computed over the Fisher scores. LDA, being explicitly optimised for Fisher separability, receives the highest weight automatically. Isomap and UMAP are fitted on stratified 2,000-point subsamples. The weighted embeddings are concatenated into an 8D fused representation. Observed attention weights: PCA 0.311, LDA 0.347, Isomap 0.264, UMAP 0.078.

Fig. 2. Fisher discriminant scores and corresponding softmax attention weights for each manifold embedding method. LDA receives the highest attention (0.347) due to its supervised optimisation for class separability.

Stage 3 (Supervised Contrastive VAE): A PyTorch VAE trained with the joint loss in (3) compresses the 8D fused representation to 4D. The loss includes reconstruction, KL divergence with $\beta$-annealing (linear warmup from 0 to $\beta_{max}$ over 40 epochs), supervised contrastive loss [8], and a cross-entropy classification head. Early stopping with patience 15 is used. At inference, $z = \mu$ (the deterministic mean), eliminating stochasticity. Training ran for 21–25 epochs before early stopping across repeated runs.

Fig. 3. SCVAE training loss with β-annealing curriculum learning. The loss drops rapidly in the first 10 epochs (reconstruction-dominated phase) and stabilises around epoch 15 before early stopping triggers.

Stage 4 (Hierarchical Stacking Ensemble): A two-level stacking ensemble replaces the fixed-weight voter. Level 1 consists of RF, XGBoost/Gradient Boosting, and LightGBM/MLP, each trained with 3-fold cross-validation. Level 2 is a Logistic Regression meta-learner trained on out-of-fold probability predictions [16].

V. Experimental Results and Analysis

A. Baseline Results

Table I summarises all results. All baselines achieve high accuracy (85.64%–100%), confirming the SOC dataset is well-structured and largely linearly separable. PCA at 4 dimensions achieves 99.82%, within 0.18% of the theoretical maximum despite discarding 10 features. LDA at a single dimension reaches 97.89%, which shows that inter-class separability is strong even in one projected direction. UMAP at 2 dimensions reaches 94.34%, while t-SNE at 2 dimensions reaches only 85.64%—consistent with t-SNE's known weakness at preserving global structure.

The practical implication is that any valid dimensionality reduction method on this dataset should achieve at minimum 97–99% accuracy to be considered competitive. The high baseline ceiling makes the evaluation demanding.

B. MSHDR v1 Analysis

MSHDR v1 reported 99.79% accuracy, but this result requires qualification. The execution log reveals that the Stage 3 autoencoder was bypassed entirely:

Autoencoder unavailable: No module named 'tensorflow'. Using fused features directly.

The 99.79% accuracy was achieved by the Stage 4 ensemble operating on the 6D fused representation from Stage 2, without any autoencoder compression. The fused representation, which includes the discriminative LDA component, provided sufficient signal for the ensemble to match baseline performance.

This accidental bypass actually exposed a design flaw. The v1 autoencoder trains exclusively on reconstruction loss with no class label involvement. The bottleneck learns to represent directions of maximum reconstruction fidelity—equivalent to a nonlinear PCA. On a dataset where normal traffic dominates, the bottleneck features encode how to reconstruct samples rather than which class they belong to. The Fisher discriminant criterion of such a bottleneck can approach zero, meaning the 3D latent space may have no class separability at all.

A second flaw in v1 is the equal-weight manifold concatenation. LDA's single dimension carries the entire supervised discriminative signal (recall: LDA alone achieves 97.89%), but it receives the same implicit weight as 3 PCA dimensions and 2 Isomap dimensions. The 6D fused space therefore has 1 discriminative dimension diluted by 5 dimensions of variance/noise. When fed to a reconstruction-only autoencoder, the discriminative LDA dimension is likely discarded in favour of the higher-variance PCA/Isomap components.

The third flaw is the fixed voting weights [0.4, 0.6]. These are heuristically chosen and do not adapt to the actual relative performance of the classifiers on compressed features.

C. MSHDR v2 (SCMAA) Analysis

MSHDR v2 achieved 99.76–99.80% accuracy across two runs (F1: 99.81–99.84%, AUC-ROC: 99.92–99.99%), with the SCVAE running successfully through early stopping at epochs 21–25. Each of the v1 failures is addressed by a specific design change.

The SCVAE replaces reconstruction-only training with the joint loss in (3). The supervised contrastive term pulls same-class samples together in the 4D latent space and pushes different-class samples apart. The cross-entropy head ensures the latent representation is directly predictive of class labels. $\beta$-annealing stabilises training by allowing the reconstruction quality to establish before regularisation takes effect.

Fisher-weighted manifold fusion replaces equal-weight concatenation. Each embedding method is scored by $J = \text{tr}(S_W^{-1} S_B)$ on training data, and attention weights are computed via softmax. The observed scores (PCA: 3.44, LDA: 3.55, Isomap: 3.28, UMAP: 2.06) and corresponding weights (PCA: 0.311, LDA: 0.347, Isomap: 0.264, UMAP: 0.078) confirm that LDA automatically receives the highest weight—a data-driven solution to the signal-dilution problem.

The hierarchical stacking ensemble replaces the fixed-weight voter. The out-of-fold meta-learner learns optimal combination weights from data rather than from manual tuning [16].

D. Comparative Discussion

MSHDR v2 compresses 14 features to 4 latent dimensions while achieving accuracy within 0.06% of PCA at the same dimensionality (99.76% vs. 99.82%). The difference is not statistically significant on a test set of 9,333 samples. However, the theoretical properties of the two representations differ. PCA preserves variance; the SCVAE latent space is explicitly trained for class discrimination. In deployment scenarios where class distributions shift (e.g., new attack types emerge), a supervised contrastive representation is expected to be more robust than an unsupervised one, though this hypothesis requires further empirical validation.

LDA's 97.89% accuracy from a single feature remains noteworthy. For applications where computational cost dominates over accuracy, LDA may be the most practical choice.

VI. Code-Level Technical Analysis

A. Architecture Strengths

The codebase exhibits several sound engineering practices. The pipeline has clean separation of phases with method chaining. Optional dependencies (PyTorch, XGBoost, LightGBM, UMAP) are handled with graceful fallbacks that do not crash the pipeline. Stratified subsampling prevents $O(n^2)$ blowup in Isomap and UMAP while preserving class balance. The SCVAE training uses gradient clipping (clip_grad_norm_ at 1.0) to prevent exploding gradients, deterministic inference ($z = \mu$) to remove stochasticity from predictions, and Fisher regularisation ($S_W + \epsilon I$) to prevent singular matrices.

B. Identified Issues

Several issues were identified during analysis:

OOF averaging bug: The out-of-fold meta-feature construction divides by 5 while using n_splits=3. This produces incorrectly scaled probability estimates for the meta-learner. The fix is to divide by n_splits instead of a hardcoded constant.

Scaler mismatch: StandardScaler output is unbounded, but subsequent np.clip(0,1) discards information. Since the SCVAE decoder uses sigmoid activation (which expects [0, 1] input), MinMaxScaler should replace StandardScaler.

Missing TensorFlow dependency: TensorFlow is not listed in requirements.txt, causing the v1 autoencoder to silently skip via a try/except block. Either TensorFlow should be added as a dependency or the v1 autoencoder should be removed.

t-SNE alignment: Train and test subsets receive independent t-SNE embeddings, meaning the two embedding spaces are not aligned. This should be documented as a visualisation-only metric.

VII. Conclusion

This paper presented and evaluated the MSHDR framework for dimensionality reduction in SOC network intrusion detection. The following conclusions emerge from the experiments:

Classical methods set a high bar on this dataset. PCA at 4 dimensions achieves 99.82% accuracy, and LDA at 1 dimension achieves 97.89%. Any novel method must justify its additional complexity by approaching these numbers.

MSHDR v2 achieves extreme compression without significant performance loss. The SCVAE reduces 14 features to 4 latent dimensions while maintaining 99.76% accuracy, effectively matching PCA. The joint loss formulation with $\beta$-annealing curriculum learning resolves the failure modes identified in MSHDR v1, where reconstruction-only training destroyed class structure.

Fisher-weighted manifold fusion addresses signal dilution by scoring each embedding method by its Fisher discriminant criterion and weighting accordingly. On this dataset, LDA received the highest attention weight (0.347), consistent with its supervised optimisation objective.

A critical OOF averaging bug was identified in the stacking ensemble implementation and should be corrected before deployment.

A. Research Contributions

The MSHDR v2 / SCMAA pipeline makes five original contributions:

  1. Adaptive ensemble feature selection with elbow-based cutoff combining mutual information, ANOVA, and Random Forest importance.
  2. Fisher-weighted manifold fusion with softmax attention over discriminant scores.
  3. Supervised contrastive VAE with joint multi-task loss for class-discriminative compression.
  4. $\beta$-annealing curriculum learning for stable VAE training in the cybersecurity domain.
  5. Hierarchical stacking ensemble with out-of-fold meta-learner replacing fixed-weight voting.

B. Future Work

Several directions remain open. The OOF averaging bug should be corrected. MinMaxScaler should replace StandardScaler before the SCVAE. The pipeline should be evaluated on additional SOC datasets (e.g., CICIDS2017, IoT-23) for generalisability. A systematic ablation study removing each MSHDR v2 component individually would quantify their respective contributions. Finally, direct comparison with Wright et al. [1] on matched dataset conditions would contextualise the framework's performance in the larger-scale feature regime.
